Política de Privacidade - MissiumTV Cortes

Última atualização: 26 de novembro de 2026.

O MissiumTV Cortes é uma ferramenta interna usada apenas pelo canal MissiumTV (youtube.com/@missiumtv) para publicar os próprios vídeos no YouTube.

1. Uso dos Serviços de API do YouTube

Esta ferramenta usa os Serviços de API do YouTube (YouTube Data API v3). Ao usar a ferramenta, você concorda com os Termos de Serviço do YouTube. Os dados tratados pelos serviços do Google seguem a Política de Privacidade do Google (http://www.google.com/policies/privacy).

2. Quais dados acessamos e para quê

Com a autorização OAuth 2.0 do dono do canal, a ferramenta acessa somente a conta do YouTube do próprio canal MissiumTV para: enviar vídeos; definir título, descrição, tags, miniatura e data de publicação; adicionar os vídeos às playlists do canal; e publicar comentários nos próprios vídeos. Também lê o nome do canal e a lista de playlists do próprio canal.

A ferramenta não coleta dados de outros usuários do YouTube, não usa cookies, não exibe anúncios e não vende nem compartilha dados com terceiros.

3. Armazenamento

O único dado guardado é o token de acesso OAuth, salvo apenas no computador do dono do canal (não há servidor nem banco de dados externo). Ficam também registros locais dos IDs dos vídeos enviados, para não enviar o mesmo vídeo duas vezes.

4. Exclusão de dados e revogação do acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta do Google: https://security.google.com/settings/security/permissions. Ao revogar, o token deixa de funcionar e é apagado do computador. Os registros locais são apagados em até 30 dias, ou imediatamente mediante pedido.

5. Contato

Dúvidas ou pedidos de exclusão: pelo canal youtube.com/@missiumtv.
